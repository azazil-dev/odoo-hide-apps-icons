In real Odoo usage, hiding an app removes the root icon, its entire sub-menu hierarchy, and home actions for the selected user.

Group & User Granularity

Set company-wide defaults at the Security Group level, then easily override or create exceptions for specific individual users.

Transparent Origin

Clear Source column immediately tells administrators whether an app is hidden by a Group rule or a User-specific override.

Bulk Productivity Tools

Includes Check All, Uncheck All, and Reset to Group Defaults buttons for rapid configuration of multi-app instances.

Safe & Non-Intrusive

Zero modifications to ACLs or record rules. Settings app is always protected from being hidden from system administrators.

Seamless Integration with Odoo Standard UI

Dedicated tabs under Group and User forms let administrators manage dashboard menus effortlessly.

Important Note on Security: This module controls UI Menu Visibility to provide clean, clutter-free user experiences. It is not an alternative to Odoo's backend security groups, ACLs, or Record Rules. If a user requires strict database access restriction, configure standard Odoo security groups.
