App Dashboard Visibility

Odoo 17 CE & EE Zero ACL Changes Group & User Granular Free & OPL-1

Take complete control of what every internal user sees on their Odoo dashboard. Administrators decide which root applications each security group or individual user can see — no code modifications, no tampering with security groups, and zero risk to existing access rights.

Settings → Users & Companies → Users / Groups → pilih record → tab App Dashboard Visibility

Where to Find It (Lokasi Pengaturan)

1. Group Defaults (Opsional)
Settings → Users & Companies → Groups
→ pilih group → tab "App Dashboard Visibility"

Atur default visibilitas aplikasi root untuk seluruh anggota grup keamanan.

2. User-Specific Visibility & Exceptions
Settings → Users & Companies → Users
→ pilih user → tab "App Dashboard Visibility"

Override seting visibilitas per individu lengkap dengan penanda kolom Source.

Group & User Level

Konfigurasi visibilitas per grup keamanan dan override per individu pengguna sesuai kebutuhan.

Source Column

Kolom asal visibilitas transparan: mengetahui apakah status berasal dari user override atau aturan grup.

Bulk Productivity

Tombol aksi cepat Check All, Uncheck All, dan Reset to Group Defaults dalam 1 klik.

Settings Protection

Menu Administrasi (Settings) terlindungi otomatis agar tidak dapat disembunyikan dari Administrator Sistem.

How Visibility Is Resolved (Aturan Resolusi)

1
User Override (Prioritas #1)

Jika user memiliki pengaturan individual tersendiri untuk sebuah aplikasi, pengaturan ini yang langsung dimenangkan.

2
Group Rule (Prioritas #2)

Jika tidak ada override user, aplikasi disembunyikan bila minimal satu grup milik user menyembunyikannya.

3
Default Visible

Jika tidak ada pembatasan baik di level user maupun grup, aplikasi root tampil normal di dashboard.

Penting: Modul Manajemen Visibilitas UI (Bukan Pembatas Hak Akses Data)

Modul ini bertujuan menyederhanakan dan merapikan tampilan dashboard agar bebas dari aplikasi yang tidak relevan bagi user. Modul tidak mengubah hak akses model data, Record Rules, maupun Security Groups Odoo. Jika Anda butuh membatasi akses baca/tulis data secara ketat, gunakan pengaturan Security Groups bawaan Odoo.

Panduan Penggunaan Cepat

Langkah 1 — Berikan Hak Kelola

Buka user administrator yang ditugaskan:

Centang hak akses Manage App Dashboard Visibility
Langkah 2 — Atur Group / User

Buka tab App Dashboard Visibility:

Hilangkan centang pada aplikasi yang ingin disembunyikan dari dashboard
Langkah 3 — Refresh Browser

Perubahan langsung aktif:

User cukup reload browser untuk melihat dashboard yang rapi dan terorganisir
