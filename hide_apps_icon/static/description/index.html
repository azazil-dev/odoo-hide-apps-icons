App Dashboard Visibility

Odoo 19 CE & EE Zero ACL Changes Group & User Granular Free & OPL-1

Take complete control of what every internal user sees on their Odoo dashboard. Administrators decide which root applications each security group or individual user can see — no code modifications, no tampering with security groups, and zero risk to existing access rights.

Settings → Users & Companies → Users / Groups → select record → App Dashboard Visibility tab

Where to Find It (Menu Locations)

1. Group Defaults (Optional)
Settings → Users & Companies → Groups
→ select group → "App Dashboard Visibility" tab

Configure root app visibility defaults for all members of a security group.

2. User-Specific Visibility & Exceptions
Settings → Users & Companies → Users
→ select user → "App Dashboard Visibility" tab

Override visibility settings per individual user, with transparent Source tracking.

Group & User Level

Define visibility rules at the security group level, then easily create exceptions for individual users.

Source Column

Transparent origin column immediately shows whether visibility originates from a group rule or a user override.

Bulk Productivity

Quick action buttons: Check All, Uncheck All, and Reset to Group Defaults in a single click.

Settings Protection

The Administration (Settings) app is automatically protected from being hidden from Settings Administrators.

How Visibility Is Resolved

1
User Override (Priority #1)

If a user has an explicit setting configured for an application, this individual setting wins.

2
Group Rule (Priority #2)

Without a user override, the app is hidden if at least one of the user's security groups hides it.

3
Default Visible

If neither user nor group restricts the app, it remains visible on the dashboard by default.

Important Note: UI Menu Visibility vs. Data Security

This module is designed to provide clean, focused dashboards by hiding non-relevant root menus from users. It does not alter Odoo's backend security groups, ACLs, or Record Rules. If you need strict data access restrictions, always configure standard Odoo security groups.

Quick Setup Guide

Step 1 — Grant Permissions

Open the assigned administrator:

Check Manage App Dashboard Visibility access right
Step 2 — Configure Visibility

Open the App Dashboard Visibility tab:

Uncheck applications you want to hide from groups or specific users
Step 3 — Refresh Browser

Instant effect upon reload:

Users reload their browser to experience a clean, decluttered dashboard
